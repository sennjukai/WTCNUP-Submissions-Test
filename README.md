# WTCNUP Community approved packages

This branch is the formal, signed release authority for WTCNUP community packages.

- `CommunityIndex.json`: signed single-file index.
- `CommunityIndex.sig`: detached Ed25519 signature.
- `keys/community-index-ed25519.pub`: formal public key.
- `packages/<submission_uid>/<translation_version>/submission.zip`: approved package ZIPs.

Only the protected publication workflow may update this branch.
